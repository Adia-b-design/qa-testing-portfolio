## BUG-001- Tous les produits affichent la meme image.

### 1- Information : 
- Projet : SauceDemo
- ID : BUG-001
- Type : Anomalie visuelle
- Compte : problem_user
- Statut : Identifie 
- Severite : Moyenne

 ### 2- Descriptiom du probleme :
  Tous les produits ont la meme image sur la page "Products".

 ### 3- Precondition :
  - Acceder a la page de connexion.
  - Utiliser le compte "problem_user".
 
 ### 4- Etapes pour reproduire l'erreur : 
 - Ouvrir SauceDemo.
 - Se connecter avec le compte "problem_user".
 - Acceder a la page "Products".
 - Observer si toutes les images sont les meme pour chacuns des produits.

### 5- Resultat attendu : 
Tous les produits affichent la meme image.

### 6- Resultat obtenu : 
Tous les produits affichent bien la meme image.

### 7- Impact utilisateur : 
Difficultes potentiel a identifier visuellement les produits.

### 8 - Conclusion : 
Une anomalie d'affichage a ete detectee depuis le compte "problem_user".
