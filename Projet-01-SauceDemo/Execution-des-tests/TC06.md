# TC06 – Vérification du lien About

### 1. Objectif
Vérifier que le lien About redirige correctement vers le site de Sauce Labs.

### 2. Préconditions
- Accéder à SauceDemo.
- Disposer des identifiants standard_user et problem_user.

### 3. Étapes de test
- Se connecter avec standard_user.
- Ouvrir le menu latéral.
- Cliquer sur About.
- Vérifier la redirection.
- Recommencer avec problem_user.

### 4. Résultat attendu
Les deux comptes doivent être redirigés vers le site de Sauce Labs.

### 5. Résultat obtenu
- standard_user : redirection réussie.
- problem_user : affichage de « Page not Found ».

### 6. Statut
FAIL

### 7. Anomalie associée
BUG-003
8. Conclusion
Une différence de comportement a été constatée entre les deux comptes lors de l'utilisation du lien About.
