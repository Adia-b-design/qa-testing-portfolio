## TC02 - Connexion avec un mot de passe invalide : 
# Objectif : Verifier qu'un utilisateur disposant d'un mdp invalide ne peut pas acceder a l'application.

Precondition : 
- L'utilisateur doit etre sur la page de connexion.
- Un identifiant valise est disponible.

Etapes : 
- Ouvrir la page de connexion SauceDemo.
- Saisir un ID valide.
- Saisir un MDP invalide.
- Cliquer sur "login". 

Resultats attendu : 
Un message d'erreur apparait et la connexion est refuse.

Resultat obtenu : 
Un message d'erreur apparait : " Epic sadface: Username and password do not match any user in this service".

Statut : 
PASS

Conclusion : 
L'application refuse bien la connexion a cause d'un mdp incorrect.
